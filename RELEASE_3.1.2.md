# 3.1.2 — Foxes Player Ratings and Film Tracking Controls

Redesigns Player Ratings in Foxes red, white, and black. Select a player from the roster to see a spotlight panel, stats, season trajectory, category breakdown, and game rating history. Search and position filters work with season and game views. Players without recorded games are excluded from ratings.

Film now keeps Auto Track Start/Stop, readiness status, bench-zone setup, and pending-crossing review beside the video, even with the analysis panel closed.

Auto Track remains assisted bench-crossing detection. Player identities must be assigned and crossings confirmed before they become official ice time. This release does not add automatic jersey recognition or establish full-game LiveBarn accuracy.

Preserves existing analytics dashboards, saved games, rosters, bench zones, stats imports, rating formulas, tracking history, and update/data paths.

Validation: automated tests and renderer syntax checks; interactive rating selection, filters, empty state, responsive width, and film readiness checks. The release workflow builds and validates the Windows installer before publication.
