# Changelog

This file summarizes major milestones. The detailed release notes remain in the existing `RELEASE_*.md` files and are not replaced by this summary.

## v4.1.9

- Added a scoreboard-clock preview that detects observed countdown, stoppage, and restart patterns.
- Added review, adjustment, confirmation, and dismissal of possible breaks.
- Kept suggestions non-authoritative until the coach confirms them.

## v4.1.8

- Added calendar schedule navigation and next-game preparation.
- Added film trimming and break review.
- Added bundled local player detection for the player-follow preview.

## v4.1.7

- Added compact name-and-number flags for followed players.
- Continued identity safeguards and coach review requirements.

## v4.1.6

- Simplified the film workspace and fullscreen transport.
- Added sound and volume controls.
- Added whistle pauses that exclude stopped time from tracked totals.
- Added the first player-follow and bench-crossing preview workflow.

## v4.1.0–v4.1.5

- Added private scouting and tryout/player-development profiles.
- Improved film loading and rating controls.
- Added balanced rating categories and configurable rating behavior.
- Changed overall ratings to start at 70 while preserving neutral raw scoring.
- Improved saved-game and film workflows.

## v3.1.0–v3.1.2

- Added the Coach Command Center and redesigned ratings presentation.
- Added visible film/tracking controls, season summaries, and trend-oriented views.
- Continued the transition from the earlier game-entry interface to workspace-based coaching workflows.

## v3.0.12–v3.0.16

- Added the My Games hub and integrated game-level stats workflows.
- Added stats import/export and saved bench zones.
- Added time-on-ice tracking foundations, corrections, and review safeguards.
- Added improvements for saved data, season aggregation, and release packaging.

## Earlier history

Earlier versions and historical implementation details remain documented in `VERSION_2.9_FEATURES.txt`, the older setup documents, and the complete `RELEASE_*.md` sequence.
