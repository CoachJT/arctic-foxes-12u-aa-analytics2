# 3.1.0 — Coach Command Center

Normal-channel release of the validated 3.1.0-dev.1 update. The previous prerelease was excluded by the installed app's normal updater. Version 3.1.0 is available through Check for Updates.

Includes Coach Dashboard KPIs, Top 5s and trends; Film Fit/Fill/Theater/Fullscreen and collapsible tracking tools; mixed-section Excel/CSV preview and import; Game Dashboard, Shift Timeline, line/pair overlap, bookmarks, coach notes, Game Day planning and Data Quality.

Saved-data paths, roster behavior, application identity and update repository remain unchanged. Existing bench zones, tracking corrections and Undo are preserved.

Validation: 57 automated tests, syntax and release-invariant checks, Windows packaging and the previously completed interactive smoke checks. This promotion changes release version/channel metadata, not analytics or tracking behavior.

Known limitations: Auto Track remains alpha and requires coach review. Unit GF/GA, shots and chances attribution is not implemented. Game Day plans do not automatically change live line/goalie controls. Player notes are game-scoped. Full-game LiveBarn acceptance was not performed; prior film smoke checks used a generated local video.
