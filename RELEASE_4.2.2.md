# Arctic Foxes 4.2.2

- Established the stable Windows product identity `Arctic Foxes Hockey Analytics`.
- Kept the application ID `com.foxes.hockeyanalytics` unchanged.
- Removed release-version suffixes from the Windows product and shortcut names so future installers use one application identity.
- Disabled arbitrary installation-directory selection for normal installs.
- Preserved the existing updater channel, saved-data location, season/game data, and schemas.

This release is an installer-identity repair. It does not change analytics formulas, Film logic, TOI/tracking logic, scouting logic, or saved-data behavior.
